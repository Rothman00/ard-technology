# ARD Technology

Landing page corporativa de **ARD Technology**, enfocada en presentar el perfil del equipo, stack tecnológico, proyectos destacados y canales de contacto directo. El sitio prioriza una experiencia visual moderna, animaciones fluidas y rendimiento óptimo.

## 🚀 Descripción
Este proyecto es una **landing page interactiva** construida con React, Tailwind CSS y Framer Motion. Incluye animaciones basadas en movimiento del mouse, secciones claramente delimitadas (Hero, Perfil, Stack, Proyectos y Contacto) y navegación interna mediante anchors.

Está pensada como carta de presentación profesional para clientes y aliados tecnológicos.

## 🧱 Stack Tecnológico

### Frontend
- **React**
- **Tailwind CSS**
- **Framer Motion** (animaciones y motion values)

### Estilo y UX
- Diseño dark moderno
- Gradientes radiales dinámicos
- Animaciones suaves y controladas
- Responsive design

## 📂 Estructura General

- `App.jsx` → Componente principal
- Componentes internos:
  - `TechCard`
  - `ProjectCard`
  - `ContactCard`
- Assets:
  - `logo.png`

## 🧭 Secciones del Sitio

- **Hero**: presentación de marca con animaciones y CTA
- **Quiénes somos**: perfil del equipo
- **Stack Tecnológico**: lenguajes, frameworks e infraestructura
- **Proyectos**: productos reales en producción
- **Contacto**: enlaces directos a WhatsApp

## ▶️ Ejecución del Proyecto

### Requisitos
- Node.js 18+ (recomendado LTS)
- npm o pnpm

### Instalación
```bash
npm install
```

### Modo desarrollo
```bash
npm run dev
```

### Build producción
```bash
npm run build
```
